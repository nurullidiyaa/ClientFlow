# ClientFlow

**Manage clients. Track work. Get paid.**

ClientFlow is a personal project in progress that aims to help freelancers and small service businesses manage their clients, projects, tasks, invoices, and payments in one place.

I am building ClientFlow to strengthen my practical skills in frontend development, backend API development, and database integration.

## Features Implemented

- **Client Management** — Create, view, update, and delete client records.
- **Project Management** — Manage projects and associate them with clients.
- **Task Management** — Create and manage tasks linked to projects.
- **Invoice Management** — Create and manage invoices for projects.
- **Payment Management** — Record and manage payments associated with invoices.
- **Dashboard API** — Retrieve summary data such as client, project, invoice, revenue, and pending payment totals.

## Project Status

ClientFlow is currently under development. The main CRUD workflows for clients, projects, tasks, invoices, and payments have been implemented. Further work is planned to improve validation, authentication, business logic, and the overall user experience.

The project is a learning and portfolio project and is not currently offered as a production service.

## Running Locally

The frontend and backend are separate applications and must be configured and started independently.

- Frontend: Next.js development server
- Backend: Laravel development server
- Database: SQLite

Local environment configuration and dependencies are required before running the application.
