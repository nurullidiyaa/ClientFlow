# ClientFlow

**Manage clients. Track work. Get paid.**

ClientFlow is a personal project in progress that aims to help freelancers and small service businesses manage clients, projects, tasks, invoices, and payments in one place.

I built this project to strengthen my practical skills in frontend development, backend API development, and database integration while learning how different parts of a business management system work together.

## Features Implemented

- **Client Management** — Create, view, update, and delete client records.
- **Project Management** — Create and manage projects associated with clients.
- **Task Management** — Create and manage tasks linked to projects.
- **Invoice Management** — Create and manage invoices associated with projects.
- **Payment Management** — Record and manage payments associated with invoices.
- **Dashboard API** — Retrieve summary data for clients, projects, invoices, revenue, and pending payments.

## What I Learned

Through this project, I have been practising how to:

- Build user interfaces using React, Next.js, TypeScript, and Tailwind CSS.
- Develop REST API endpoints using Laravel.
- Integrate frontend interfaces with backend APIs using GET, POST, PUT, and DELETE requests.
- Validate and store data in a database.
- Manage relationships between clients, projects, tasks, invoices, and payments.
- Implement CRUD workflows across the frontend, backend, and database.

## Project Status

ClientFlow is currently under development. The main CRUD workflows for clients, projects, tasks, invoices, and payments have been implemented.

Further improvements are planned for input validation, business rules, authentication, dashboard data integration, and the overall user experience.

This is a learning and portfolio project and is not currently offered as a production service.

## Running Locally

The frontend and backend run as separate applications.

**Backend**
1. Navigate to the `backend` directory.
2. Install the PHP dependencies using Composer.
3. Configure the local environment and SQLite database.
4. Start the Laravel development server.

**Frontend**
1. Navigate to the `frontend` directory.
2. Install the Node.js dependencies.
3. Start the Next.js development server.

Local environment configuration and dependencies are required before running the application.
